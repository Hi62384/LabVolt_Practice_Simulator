# Pencil case integration

`case.gd` extends `Control`. Give it a 292 px wide region at the right edge; the component moves its drawn fabric case internally between a 42 px peek and the open position. It does not move the workspace's root control and cannot be dragged. `body.gd` draws the zipper, pockets, and three physical tools. The compact properties popup appears only while a tool is selected.

Call `configure(initial_tool, properties)` before or after adding it to the tree. Valid tools are `answer`, `pencil`, `eraser`, `text`. Only three tools are visible. A selected tool keeps the case open; clicking it again emits `tool_selected("answer")` and permits stowing. `set_tool` changes the active tool and emits this signal if it changes. Call `set_selection(item)` after canvas selection changes; pass `{}` to clear.

`properties_changed` emits a full dictionary for tool defaults. It emits `{ "_scope": "selection", key: value }` when the selected text's properties change. The workspace must convert selected `equation` to annotation `kind` (`equation` or `text`). Selected annotation `angle` is emitted in radians to match `paper_annotations.gd`; its control displays degrees. The component never mutates annotation storage. `text_action("edit")` requests focus for the selected text editor; `text_action("bake")` requests baking **only** the selected annotation. `duplicate` and `delete` are available after `set_supported_text_actions(["edit","bake","duplicate","delete"])`; the extra buttons stay hidden until the workspace implements them. The workspace should record the before and after state in its existing undo mechanism, mark only the selected item baked, and clear selection. Neither action should flatten ink or other annotations.

Defaults: `color` HTML hex, `width` paper brush/eraser size, `hardness` and `opacity` 0–1, `font` Sans/Serif/Mono, `font_size` px, `angle` radians for page objects, `equation` bool. Pencil, eraser, and text keyboard shortcuts are P, E, and T when a text editor does not own focus; Escape selects `answer`. `cursor_texture(tool)` returns a dedicated SVG texture for the workspace to apply only to its paper canvas cursor.
