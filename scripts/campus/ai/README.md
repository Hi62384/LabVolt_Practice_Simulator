# Host OpenAI connection and model comparison

OpenAI Settings is available from Singleplayer and Host Game setup. It can use a key entered for this game process or `OPENAI_API_KEY` from the process environment. The key stays in the host process and is excluded from saved settings, usage records, and multiplayer messages. The connection starts disabled unless configured. The game's output-token setting and the provider's own rate limits still apply.

The local mock is `tests/campus/ai/openai_fixture_server.py`. Run `test_host_openai_client.gd` against that mock to verify request formatting, usage, persistence, and error handling. Run `test_model_comparison.gd` without a server to verify the rate calculations and exact benchmark matching.

The picker reflects model IDs returned for the connected key and filters them by the documented endpoints used by Campus OS. A successful list response confirms visibility to the key. A successful request confirms that specific endpoint, model and configuration.

The catalog checked on November 26, 2026 uses [API pricing](https://developers.openai.com/api/docs/pricing), [model documentation](https://developers.openai.com/api/docs/models), [reasoning guidance](https://developers.openai.com/api/docs/guides/reasoning) and [deprecation notices](https://developers.openai.com/api/docs/deprecations). Price records show USD and the billing unit for the modality. Cost estimates use the displayed workload, service tier and published rates. Thinking tokens count as output. For invoices and organization totals use the provider usage dashboard.

Benchmark records come from the [GPT-5.4 mini and nano announcement](https://openai.com/index/introducing-gpt-5-4-mini-and-nano/) and [GPT-6.2 system card](https://deploymentsafety.openai.com/gpt-6-2-astra-sol#gpqa-diamond-no-tools). A score describes the specific benchmark, model ID, and published effort. Default preview shows the cited benchmark result with its published effort. When a source omits effort, the result is visible in the default preview only. GPT-5.4 mini and nano share a source and published comparison setup. Compare the GPT-6.2 system card separately when methodology differs.

The optional local evaluation requires an explicit confirmation before sending requests. It uses an eight-question fixed suite, caps output at 512 tokens per question and supports pausing after an in-flight question. Its results and cost estimates belong to the local test and are shown independently of published benchmarks. Editing preview filters does not make API calls or change the in-game request model and effort.
