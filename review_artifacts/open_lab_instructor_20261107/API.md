# Open Lab practice academic API

`res://review_artifacts/open_lab_instructor_20261107/practice/practice_service.gd` owns the pure course/worksheet preparation. Host calls `issue_for_room(room_id, provider, seed)` after resolving a trusted room ID; M101 maps to ELM253, M103 to ETY155. It returns an existing-generator project with `practice_scope=ungraded`, `practice=true`, `is_exam=false`, no timer/grade weight. Host alone calls `_give(peer, project, true, false)` to create the private physical sheet. Study resources call `issue_for_course("MTH147" or "MTH255", provider, seed)` for independent ungraded lecture practice using existing math generators. `_give` attaches existing teaching stages and math paper policy, and math_course_paper renders its question pages. All normal paper possession, placement, saving and owner checks remain in school_session.

The patch in this directory is a surgical shared-session handoff, not applied during active play. It uses the actual host `activity.room.id`, authenticated `game.session.poses[peer]`, `room_bridge.contains`, `_near`, roster and identity to issue a private sheet. The UI owner consumes the room mapping and host request operation. No M101 equipment subtree or materials are changed.
