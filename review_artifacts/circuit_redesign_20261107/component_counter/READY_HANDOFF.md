# Component Counter private assembly for sole integrator

`assembly_patches.json` is an ordered, preimage-bound integration packet. `check_assembly.py` passed source-contract verification. It leaves live source untouched. Copy its four candidate modules to the declared destinations, then replay its 17 unique shared patches only if all file hashes still match. Do not apply subsets in a running session. The integrator owns any collision with concurrent core UI work.

The store panel is reached by M102 `shop_station` page `shop`; `trade` remains M102. The packet limits the physical station router to those two pages. The shop root mounts Components, Bundles, Equipment through one compact section selector. Component cards use catalog entries from `profile.catalog()`, cached SVG thumbnails, family/search filters, owned counts from the profile snapshot, and canonical rating/quantity quote intents. `shop_adapter` retains the authenticated component purchase/receipt path. Bundle and equipment cards call the existing `purchase_bundle`, `buy_box`, `buy_analyzer`, and `upgrade_capacity` methods. Their results refresh the UI; random box receipt text includes received item names. The economy snapshot comes from the authenticated host when connected, otherwise from the local playtest policy; the panel displays one `$∞` or grouped dollar balance.

M207 Mount sequence: copy `legacy_cosmetic_adapter.gd` and `legacy_wear_section.gd`, apply the store panel and campus integration patches, then verify actual cards, authenticated `cosmetic` receipt acceptance, ownership refresh, and Wear save/appearance update. Only after that apply `migration_after_m207_verified` to remove the temporary legacy wear panel from M102. That migration preimage is against the assembled shop function, not current live source. Exact item IDs/prices/settings remain in ElectronicsProfile.COSMETICS. Other M207 avatar purchases remain on their existing separate operation path.

The header patch suppresses the old electronics title/balance/Close on the shop page because the store panel owns all three. The old permanent shop copy is blanked. The page-level shop scroll is disabled; Components has its own scrolling grid, and Bundles/Equipment have independent scroll containers. The selected component is cleared when filtered out. A stale saved search that hides everything at opening is cleared; a new no-result search gets an explicit empty state. Pending purchases lock the picker to avoid an unrelated selection during a receipt wait.

Source checks covered ordered unique patch replay, resource existence, real purchase callback references, M102 routing, M207 buy/Wear callbacks, migration preimage, and component receipt signal. These checks are not Godot parsing or visual/runtime acceptance. Runtime owner must later verify 1920×1080 and 1366×768, M102/M207 world reachability, keyboard and pointer focus, catalog population, custom values and quantity limits, stored normal/$∞ wallet, bundle contents/odds, offline and multiplayer receipts, character appearance, save compatibility, and immediate shared inventory visibility in the circuit picker.
