# Apply-ready shared patches

The patches in this directory are generated by `build_patches.py` from fresh source preimages. The script asserts every replacement anchor occurs exactly once and writes full SHA-256 preimage files. Source files are not modified by the generator.

Apply together after the shared-file owners finish their current edits:

```powershell
git apply --check --ignore-space-change review_artifacts/class_start_20261106/scripts__school_session.gd.patch review_artifacts/class_start_20261106/scripts__front_menu.gd.patch review_artifacts/class_start_20261106/scripts__paper_ui.gd.patch review_artifacts/class_start_20261106/scripts__school_world.gd.patch
git apply --ignore-space-change review_artifacts/class_start_20261106/scripts__school_session.gd.patch review_artifacts/class_start_20261106/scripts__front_menu.gd.patch review_artifacts/class_start_20261106/scripts__paper_ui.gd.patch review_artifacts/class_start_20261106/scripts__school_world.gd.patch
```

`--ignore-space-change` is required because the source files use CRLF while the generated patch uses LF. The combined `--check` succeeded against the captured preimages on 2026-11-06.
