# Desktop UI handoff

Owner: desktop UI lane. Copy `desktop_ui.gd` into `scripts/campus/computers/desktop_ui.gd`. Create one local `CanvasLayer` with one instance of this `Control`, then call `computer_ui.build(game.computers, game)` after `ComputerSessions.build(game)`. Keep `computer_ui: Control` on game. No station creates a desktop. A nonempty owner-only snapshot opens it and calls `game.release_mouse()`; an empty snapshot clears private content, calls `game.capture()`, and emits `closed`.

In `game.gd`'s `_input`, before its generic Escape branch, forward Escape while `computer_ui.visible` to `computer_ui.request_close()`, mark the event handled, and return. The existing game Escape handler runs earlier in tree order and otherwise opens the pause menu. Ctrl+S is handled by the desktop. The session handles authoritative sitting and standing; `game.release_mouse()` disables first-person input while typing.

The UI reads `files` as the session's path to `{text,version}` dictionary, `editor.path`, `lease`, `revision`, sanitized owner-only `assignments`, and public `materials`. It sends only the session contract requests and never receives a profile or peer ID. New files use save with version zero. Drafts survive file and app switches until an authoritative save snapshot acknowledges them. Leaving with drafts asks for explicit discard. Browser and code execution are visibly unavailable. Course work shows public teaching materials and sanitized assignment summaries. The session owner's `course_desktop.gd` extends this view with existing question answer controls and refresh; use that subclass for full classroom integration. An existing local paper can be opened through the established paper workspace after host-confirmed computer exit. Lecture submission uses the session's authorized academic operation. No student text is copied to the shared teaching board.

Rename is supported by the current `ComputerSessions` candidate. The UI sends `{op:"rename",path,new_path,lease,revision}` and switches paths only when a private snapshot contains the destination. The session validates source/destination and increments file version; the UI keeps drafts on errors. A session implementing `supports_operation("rename")` can explicitly disable it; absent that optional method, the current `ComputerSessions` contract enables the button. Lease changes clear pending rename, drafts, and editor content.
