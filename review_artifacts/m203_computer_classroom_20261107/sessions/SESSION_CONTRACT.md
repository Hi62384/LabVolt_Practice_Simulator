# Session integration contract
Ownership: sessions lane owns candidate scripts/campus/computers/{computer_sessions,virtual_files,local_documents}.gd and tests. Main integrates; no shared source edited.

Create ComputerSessions Node as game child named ComputerSessions identically on all peers, call build(game). Room registers stations via register_station(id: String, chair_index: int, anchor: Vector3) on every peer in deterministic order after chairs build. IDs <=48 ASCII letters/digits/_/-. Existing game chair authority remains authoritative. request({op:"enter", station:id}) claims the existing chair; desktop opens only after host confirms chair ownership. request({op:"exit", lease:current_lease}) closes session and uses existing stand authority. Occupancy signal supplies public station->peer only. Private signal desktop_changed(snapshot) fires solely on owning client. snapshot includes lease, station, files, editor, revision. request save/editor/answer/submit includes lease and revision, never owner/profile IDs. UI uses save {path,text,version}, editor {path,cursor}, answer {paper,question,value}, submit {paper}; unavailable browser/run return explicit errors. desktop_changed empty closes UI. UI must release keyboard/mouse on empty and bind local profile before use.

Client local profile persistence uses school's accepted local_identity, never a client-supplied remote identity. The host has only connection-scoped documents, erased on disconnect; clients restore their own bounded local snapshot after enter. No host lookup by claimed identity (existing identity protocol does not authenticate cross-device identity). Local profile files are not secrets from the machine owner. Host never broadcasts documents. Restore is accepted once per connection before edits; stale lease/revisions rejected. Host crash leaves existing academic policy unchanged; last acknowledged local documents survive. No grade system changes. Existing paper authority handles answers/submission; unsupported code execution/browser explicitly fail closed.

Status: contract published before implementation. Final API and runtime fixture details appended in handoff.

Final API detail: assignment answer request uses `{op:"answer",paper:id,question:index_as_string,value:text,lease,revision}`. Unsupported `run`/`browser` also require current lease/revision. Persistence files use a fixed hashed local identity filename and an atomic temporary-file rename; all document names remain logical paths, never interpolated into OS paths. UI must explicitly save editor text; closing does not serialize unsaved widget buffers. UI code must not retain private snapshot/editor widget contents after desktop_changed({}) or local profile changes.

Assembly API final: main adopts classroom_adapter.gd + course_desktop.gd and assembly_shared_patches.json; see HANDOFF.md. rename {path,new_path}, refresh {} supported with current lease/revision. Snapshot exposes `assignments` (safe project questions, own answers/mark, submission eligibility) and public `materials`; it does not expose raw `papers`. All question answer edits flow into school.apply. Adapter owns input gating and safe stand exit; room's20 static station anchors are paired with existing gameplay chairs without changing multiplayer cap.
