# Equation typesetter contract

`paper_annotations.gd` owns the exact raw source in each annotation's `text` field and the persistent `kind` (`text` or `equation`). The host stores those fields unchanged, within its existing length and ownership checks. A separate equation component under `scripts/ui/paper_workspace/equations` should provide pure layout/validation for `source: String`, `font: Font`, `font_size: int`; return measured bounds, drawable glyph/line primitives or a drawing helper, and a precise error without rewriting source. `paper_annotations.gd` will consume it for draw and hit testing once available.

Required examples: `a/b`, `(a+b)/(c+d)`, `x^2`, `x_1`, nested groups, literal Unicode symbols, and malformed parentheses. The observed source `(((33)(66)/33+66)^2) + 3)` has an unmatched closing parenthesis (depth -1); report that exact source and error, never auto-balance or silently re-associate it. Fraction and power layout must agree between measurement and painting. Text mode always renders literal characters. Invalid equation source must remain editable and persisted exactly, with a visible error and literal fallback. The UI must make the current mode visible on selection and preserve exact source across edit/save/reopen. No equation evaluation or grading.
