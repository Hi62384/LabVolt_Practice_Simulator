# Menu branding and layout integration

Private patch: `FRONT_MENU_VISUAL.patch`. Production preimage `scripts/front_menu.gd` SHA-256 `37B8B30D6CCFA474A8AA4BD963C10822E393C85B4672208B30C34678F1063766` at patch creation. Apply only after the integrator's math-course repair; resolve against the latest production file if its shared context changed.

This patch changes only presentation in `build()`, `_layout_menu()` and `home()`. It sets the identity to LAB/VOLT / COLLEGE SIMULATOR and the tagline to Learn. Explore. Experiment. The backing panel is 84% opaque and the full-screen scrim 4.5% opaque so the real campus remains visible. On home/join/pause the panel targets 440px wide and at most 690px high, anchored 32px from the top-left. Host, View Courses, character and settings pages retain their existing wider/scrollable layouts. For 1920×1080 and 1366×768, the compact home panel targets 440×690px and 440×690px respectively; the right side remains open for the flythrough. On smaller viewports, width and height clamp to the screen margin. These are source geometry calculations, not screenshot measurements.

The seven current home routes remain unchanged: Host Game, View Courses, Join Game, Character Customizer, Electronics Shop & Kits, Settings and Quit. The patch does not touch course catalogs, class hosting, attendance/marks, settings values, keyboard focus, character footer, pause routes or session callbacks. It adds no Resume or Open Lab action.

Camera owner hooks: menu camera lifecycle should be driven by `front.home()`/`front.entered()`/`front.pause_menu()` or a game-owned visibility coordinator, never by this presentation patch. The existing `front._process()` still positions the old preview camera every frame when `not in_game`; the camera owner must replace or disable that writer so it cannot override the cinematic camera. `front.leave_game()` returns to `home()`, and `front.entered()` switches to gameplay; coordinate these with camera activation/deactivation. Route definitions and world streaming belong to the camera/routes owners.

No live production edits, engine run, GUI, screenshot or user-save actions occurred. The supplied reference image was not viewed as pixels. The integrator should perform the safe-window 1920×1080 and 1366×768 visual pass, check seven button hit targets and camera/background contrast, and adjust opacity/height if necessary.
