The unmodified npm dist/cjs trees and both MIT license texts are under
scripts/firmware_backends/vendor. No install scripts are used. Preserve their
license texts and copyright headers in all redistributions.

Required trusted host runtime: Node.js 20.19 or newer. Tested with 22.15.0.
Node is NOT included. Configure its absolute executable path on the host, never
from a player-controlled saved program. A future bundled Node distribution needs
its own license and third-party notices. The backend never installs packages,
downloads firmware, opens a listener, or runs compilers during gameplay.

Export: Node cannot read Godot PCK resources. Ship bridge.cjs, machine.cjs and the
vendor trees as loose files beside the exported game; supply that absolute
directory to NativeRuntime.load_program(..., backend_directory). Do not assume
Godot's default export filter includes .cjs/.js/.d.ts/LICENSE files. The project
was NOT exported or integrated into the live game by this worker.

This is staged native instruction execution, not a claim of complete boards:
Uno: ATmega328P at 16 MHz, 32 KiB flash, 2 KiB SRAM; GPIO, ADC, 3 timers/PWM,
external interrupts through engine pin inputs, USART; disconnected SPI/I2C
produce open-bus 0xff / NACK. No ATmega16U2 USB bridge, EEPROM persistence,
bootloader upload protocol, VIN regulator, current/thermal damage, or analog
comparator validation.
Pico: one Cortex-M0+ core at a fixed 125 MHz; 2 MiB loaded flash limit; raw flash
image plus vector offset (default 256). GPIO, ADC, PWM, UART tested. No boot ROM
is loaded; firmware must not call ROM routines. No MicroPython/Pico SDK blanket
compatibility claim, USB transport, second core, wireless, Pico 2/RP2350, PIO or
DMA validation. Pico accepts 3V3 logic rail input, not 5V GPIO or VSYS power.
GP23/24/25/29 are internal Pico signals, not extra header pads. Physical header
placement, regulators, internal board wiring and onboard LED circuits require
integrator-owned board models. The adapter's node list is a logical interface.

UART monitor is a peripheral byte endpoint, not an electrical UART wire model.
SPI/I2C events are observations of disconnected controllers; external electrical
bus slaves, pin-edge serialization, arbitration and bus loading are unfinished.
Do not use these transaction events to update a screen through unwired signals.
Native timing is instruction-driven; electrical input voltages are sampled once
per requested slice. Output edges carry cycle timestamps. The host must gate
circuit time until the reply arrives and replay edges or reduce its timestep.
The default 0.5 ms solver cannot resolve all MCU PWM/SPI rates. NativeRuntime
fails closed if output-event or instruction limits would silently lose data.
Electrical drivers: explicitly approximate 40-ohm outputs, 30k pulls, 1e12-ohm
inputs, 1k logic-rail load. No manufacturer-characterized silicon model.
