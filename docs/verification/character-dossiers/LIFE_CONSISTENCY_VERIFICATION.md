# Personal-life consistency boundary verification

An independent review found that a proposed memory's canonical value was not checked against its quoted spoken detail. A model could say that an established lifting record was a different number while proposing the old number as the canonical value. The previous spoken check exempted a topic as soon as it appeared in the proposals, so the conflict could pass both checks. Value equality also reused retrieval stop-word normalization, which discarded “not” and could treat a negative statement as its opposite.

The corrected ledger separates retrieval normalization from canonical value comparison. Canonical comparison preserves words and negation. A canonical numerical value absent from a quote containing a different literal number is rejected. A written quantity alongside a numeric date can receive semantic review rather than being mistaken for a numerical contradiction. Nonliteral canonicalization, including a spelled-out quantity or a descriptive label inferred from prose, requires the existing semantic consistency review. Spelled-out personal quantities also require review when the model omits a proposal. Relevant numerical claims are checked within their sentence or subject clause; a correct number about another subject cannot conceal a contradictory assertion. A mixed statement containing the old number and an unexplained new number requires review. Unrelated conversational negation in another sentence does not automatically trigger review.

Explained current-record updates remain possible, and their earlier values remain in history. Historical corrections retain their stronger revision requirement. New independent subjects remain expandable. Persistence timestamps are excluded from the set of spoken personal facts.

`tests/campus/academics/dossier/test_life_memory_consistency.gd` passed all 24 assertions against the production ledger on Godot 4.5.1 Mono. The production dossier pipeline passed 39 checks, the interaction pipeline passed 45 checks, and inspector privacy/transport tests passed in the final targeted rerun. Versioned memory and long-speech playback regressions were also rerun after the ledger change. Logs are included in this folder. These tests establish validation and persistence contracts using authored fixtures; they do not establish live-model naturalness or perfect semantic interpretation.
