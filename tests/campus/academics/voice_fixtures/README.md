# Synthetic spoken test fixtures

These three WAVs contain original LabVolt test phrases, synthesized with
FFmpeg's `flite` filter and the CMU Flite `slt` voice. They are not recordings
of players and were not generated by a cloud provider. `manifest.json` records
the exact text, duration and SHA-256 of each file.

Run `python tests/campus/academics/voice_fixtures/generate.py` with an FFmpeg
build that includes libflite and `slt` to regenerate them. The checked-in files
were generated with FFmpeg 7.1.5. The script resamples the output to mono 16 kHz
PCM16 and rewrites a canonical WAV header. Only these newly synthesized WAVs
are included; no Flite binary, voice model or original speech database is
redistributed here. Flite is a fixture-preparation dependency only.
